# JMETER

Para visualizar los test de carga realizados con JMeter seguir los siguientes pasos:

> [!TIP]
>
> Descomprimir el archivo `jmeter.zip` en una ubicación de su preferencia.
> Posteriormente abrir el index.html que se encuentra dentro de la carpeta descomprimida.
> El archivo se abrirá en el navegador predeterminado y podrá visualizar los resultados de las pruebas de carga realizadas.
> Para una mejor visualización, se recomienda utilizar navegadores como Google Chrome o Mozilla Firefox.
